# HarborFlow Operations

## Language

**Terminal Permit email template**:
A named, shared set of recipients, CC recipients, subject, and message text used to prepare an email about a Terminal Permit. A template can be associated with a Terminal and selected for a particular Job.

**Terminal Permit email draft**:
An email prepared for a particular Job from a Terminal Permit email template. Its recipients, subject, and message can be adjusted before the user sends it from Outlook.

**Hotel branch**:
A hotel at a specific address. Hotels with the same name at different addresses are separate branches.

**Hotel email template**:
A named, shared set of To and CC recipients, subject, and formatted body for a hotel branch. A branch may have several templates for different booking purposes.

**Hotel email draft**:
An editable email for a particular Hotel booking, belonging to the account that prepared it. It can use a Hotel email template and details from the booking and its Job.
