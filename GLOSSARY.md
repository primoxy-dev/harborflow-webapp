# HarborFlow Operations

## Language

**Terminal Permit email template**:
A named, shared set of recipients, CC recipients, subject, and message text used to prepare an email about a Terminal Permit. A template can be associated with a Terminal and selected for a particular Job.

**Terminal Permit email draft**:
An email prepared for a particular Job from a Terminal Permit email template. Its recipients, subject, and message can be adjusted before the user sends it from Outlook.
